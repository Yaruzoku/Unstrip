# Unstrip

A simple client-side Minecraft mod that prevents accidental log stripping.

### Features
- Toggle log stripping protection with `Y`.
- Protection enabled by default.
- Fully configurable keybind through Minecraft Controls.
- Vanilla stripping behaviour when protection is disabled.

### Installation
Requires Fabric Loader and Fabric API.

Place the Unstrip JAR into your Minecraft `mods` folder and launch the game.
